# C++学习规划和任务目标

更新日期：2026-10-14。学习标准：C++20。此文件记录长期方向，具体进度以同目录《当前完成进度.md》为准。

## 1. 使用方式与教学约定

- 每次开始学习，先完整读取本文件和《当前完成进度.md》，从后者的“下次从这里继续”恢复，不从头重复教学。
- 每次结束学习，更新进度文档：本次知识点、代码所在位置、预测与验证结果、尚存误解、下一步任务。长期方向变化时再更新本文件。
- 用户负责实现；助手负责解释、分级提示、代码评审和验收。除非明确要求，不代写整个练习或直接修改学习代码。
- 一次只教一个主概念。新语法先拆解，再预测、尝试、运行、解释、制造可控错误、修正总结。
- 用户不想重复敲已懂的代码时，允许口头验收；不能把口头答对记成代码实现或运行验证。新增派生类但只替换公式等重复练习可跳过。
- 项目必须服务于新知识，不为堆功能延长同一个项目。一个项目达到目标后可以换独立项目。
- 评审区分必须修复、建议改进、拓展思考。检查正常输入、边界、错误路径和生命周期。
- 不以算法刷题量衡量本路线进度。Book Manager 工程化、算法训练、总实习规划由各自任务负责。
- 默认每周两次，每次 60～90 分钟；按掌握情况推进，不承诺固定日期学完。

## 2. 参考资料与使用原则

1. [菜鸟教程 C++ 教程](https://www.runoob.com/cplusplus/cpp-tutorial.html)：用于查基础语法、类与对象、继承、多态、文件流、异常、模板以及 STL 的主题入口。本次核对了教程目录，不把评论区当权威规范。
2. 用户本地书籍：`D:/Book/C++ Primer第五版中文版.pdf`。此前封面核对实际为 Stephen Prata 的《C++ Primer Plus》第五版，而非《C++ Primer》；不要根据文件名套用另一部书的章节。此前核对的相关目录主题：类与动态内存、继承、代码重用与模板、异常、string/STL、文件输入输出。精确页码与章节标题需要使用时再查原书，不虚构页码。
3. 书籍较旧，作为概念讲解补充，不照搬旧式资源管理方案。以 C++20 实验补齐移动语义、Rule of Zero、unique_ptr/shared_ptr/weak_ptr、override、现代模板等内容；不推荐使用已淘汰的 auto_ptr。
4. 最初的《现代 C++ 学习交接》作为教学边界和学习目标依据。资料是路线参考，不要求逐页读完或照抄全部例子。

## 3. 已有基础与长期验收目标

已有基础：变量、分支、循环、函数、类、构造函数、封装、指针与引用、const、string/vector、enum class、头文件与实现分离、文件流、Lambda 初步使用和常见算法。

最终应能：

- 区分作用域、对象生命周期和自动/静态/动态存储期；不能简单把“对象是否在堆上”等同于“谁拥有它”。
- 根据所有权选择值、引用、裸指针、unique_ptr 或 shared_ptr，解释借用的有效期。
- 使用标准库和 RAII 自动管理资源，解释提前返回和异常时的清理。
- 区分拷贝构造、拷贝赋值、移动构造、移动赋值；理解表达式值类别、std::move、Rule of Zero/Five。
- 解释共享所有权、弱观察、循环引用、lock 和悬空引用。
- 正确使用虚函数、抽象接口、override、虚析构，识别对象切片，比较继承与组合。
- 使用容器、迭代器、算法和模板，说明容量变化与失效规则；处理空数据、错误输入和资源失败。
- 完成一个边界清晰的小项目，并用自己的话说明每类对象的创建、所有权、借用和销毁时机。

## 4. 项目路线与任务目标

### 阶段 A：生命周期观察实验

实际目录：`01_lifetime/`；工具链检查在 `00-toolchain-check/`。

任务：实现 Tracer，观察嵌套作用域、同作用域逆序析构、临时对象、提前返回。补充静态局部对象、自动与动态存储期、返回局部对象指针或引用的危险。

验收：预测顺序并与输出对照；说明构造完成后对象可用，离开作用域触发局部对象析构；区分变量名作用域与对象生命周期。静态存储期尚不能因已完成 Tracer 就视为掌握。

参考主题：作用域、存储类、类的构造和析构。

### 阶段 B：Task Runner

实际目录：`task-runner/`。

任务：用 TaskSession 在构造时开始计时、析构时记录结束；使用 ofstream 追加日志；TaskInfo 保存值数据，TaskRunner 保存 vector 并支持拷贝/移动提交。

新知识：RAII、成员析构顺序、chrono、值语义、const 引用、移动重载、命名右值引用表达式仍是左值、Rule of Zero。

验收：日志追加有效；提前返回仍记录结束；复制后的 string 数据独立；解释 push_back 内发生的复制/移动；不能把“进入移动重载”的日志本身作为实际移动发生的唯一证据。

补课边界：Rule of Five 的手动资源管理场景尚未系统学习，另设小实验，不为它重构现有 TaskRunner。

参考主题：类、动态内存、重载、文件流；移动语义使用现代补充。

### 阶段 C：文本查询工具

实际目录为 `texr-search/`（现有拼写，暂不重命名）。

任务：读取多行文件；map 统计词频；set 记录去重行号；交互查询直到 quit；文件词和查询词统一标准化。

新知识：getline 与格式化提取、istringstream、嵌套容器、find/end、map 下标的插入行为、at、迭代器、字符分类与显式转换。

验收：重复词、空行、空文件、文件不存在、查无此词、大小写与标点、纯标点、退出命令。查询不应改变索引；空行仍计行号。当前标准化针对简单英文/数字练习，不宣称支持中文分词或 Unicode 大小写；删除内部标点会把两段字母连起来，需能说明此限制。

可选扩展：保存原文和按行显示；封装 TextIndex。用户已选择跳过机械实现，相关概念口头验收即可，但记录为“未实现”。

参考主题：string/STL、关联容器、文件和流。

### 阶段 D：图形面积计算器（当前主项目）

实际目录为 `shape-caclulator/`，当前矩形类名为 `Ractangle`；属于拼写问题，后续需要时统一，不影响概念教学。

任务与递进：

1. Shape 与矩形：public 继承、virtual、override、基类引用调用。
2. 对象切片实验，再将 Shape 改为纯虚接口，保留虚析构。
3. unique_ptr/make_unique 管理矩形，移动所有权，vector<unique_ptr<Shape>> 管理图形。
4. 参数表达借用或接管、工厂函数返回所有权、erase/clear 与借用失效。
5. 用独立片段学习 shared_ptr、weak_ptr、reset、lock、循环引用，不为演示而把原项目全部改成共享所有权。
6. 迭代器与 vector 重新分配：区分元素移动和堆上图形地址不变。
7. 尺寸检查和异常处理：throw/try/catch、what()、异常传播与 RAII。

验收：能解释智能指针与对象的区别；抽象基类不能实例化但可引用派生对象；拥有者退出与借用失效；正数、零、负数尺寸路径；异常后局部资源自动清理。圆形重复公式练习可口头替代。

参考主题：继承、多态、抽象接口、动态内存、异常；智能指针采用现代标准库。

### 阶段 E：泛型统计工具（未开始）

建议新目录：`generic-statistics/`，开始该阶段时再创建。

目标产物：可对 int、double 数据做计数、筛选、累计和统计的小工具。

递进：函数模板与类型推导 → 迭代器区间和标准算法 → Lambda 值捕获/引用捕获及生命周期 → 类模板 → 用 concepts 表达简单约束（理解模板后再加）。

任务目标：同一模板处理多种数值类型；说明模板参数与普通函数参数区别；处理空范围；选用 accumulate/count_if/transform 等算法；识别引用捕获导致的悬空问题。

验收：至少两种类型、空数据、单元素、混合正负值；解释错误类型为何不能实例化。返回值缺失可引入 optional，数值溢出和精度问题按实验需要讲解。

参考主题：模板、泛型编程、STL、算法与函数对象。

### 阶段 F：资源与异常安全专项（未开始）

用独立的教学型资源包装器观察特殊成员函数，不把手工 new/delete 作为日常首选。先用标准容器展示 Rule of Zero，再解释确需直接管理资源时的 Rule of Five。

任务目标：区分四种拷贝/移动操作；析构与异常传播；构造失败后的成员清理；基本保证与强保证；理解 noexcept 对移动和容器策略的影响。

验收：无重复释放和悬空访问；用日志或合适的诊断工具观察复制/移动；能解释为什么生产实现通常交给标准库。

### 阶段 G：综合小项目与查漏补缺（未开始）

候选：小型测量数据分析器，组合文件解析、标准化、容器、泛型统计、错误报告和值语义。选择确有多态需求时才加入接口，不为使用所有语法强行设计。

交付：独立源码、简单使用说明、可复现示例、关键边界验证、所有权口头讲解。补齐命名空间、头文件依赖、const 正确性、容器选择、必要的运算符重载。

并发、网络、Web 编程和大型工程化作为后续可选路线，不在当前语言基础尚未验收时提前铺开。
