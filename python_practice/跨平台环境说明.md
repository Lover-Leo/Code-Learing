# Windows 与 Mac 共用 Python 学习代码

2026-10-29：共享的VS Code配置已改成双平台。Mac已实际运行验证；Windows配置与安装脚本已准备，目前没有连接到Windows电脑，尚未在Windows执行验收。

## 两台电脑如何共用

`.py`源码、两份学习文档、`.python-version`和仓库中的`.vscode`配置可以一起同步。Python解释器、虚拟环境、已安装的库和VS Code扩展需要在各自电脑上安装，不能把Mac的环境目录复制到Windows。

两端统一使用Python 3.14系列和`python`命令；补丁版本由各台电脑安装时可用的版本决定。共享的Python运行配置不包含Mac用户名或Windows盘符。

VS Code默认寻找当前用户目录下的`.local/share/venvs/python-default`，自动识别其中的Mac `bin/python`或Windows `Scripts/python.exe`。调试器使用当前选择的Python解释器。原有C++启动项与编译任务保留。

## Windows首次安装

先把本仓库的最新文件同步到Windows。在VS Code中打开整个`Code-Learing`文件夹，在该文件夹的PowerShell终端执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\.vscode\setup-python-windows.ps1
```

命令只对本次运行放行脚本，不永久改变执行策略。安装过程需要联网。脚本会检查VS Code，在需要时通过WinGet安装用户版；安装或复用uv及Python 3.14，建立带pip的用户学习环境，设置用户PATH、Python运行/调试/补全扩展、全局默认解释器与Python专用快捷键。现有编辑器设置会先备份；JSONC注释与排版会规范为标准JSON，其他设置及C++配置保留。

成功后关闭并重新打开VS Code及其终端。若这个工作区以前选过其他解释器，运行`Python: Select Interpreter`，选择用户目录下`.local/share/venvs/python-default/Scripts/python.exe`。

## Mac当前状态与恢复配置

这台Mac的Python与pip已经安装。需要重新应用通用设置时，在本仓库根目录执行：

```bash
python .vscode/configure-python.py
```

这个命令要求已有uv和Python学习环境；缺少学习环境时会通过uv创建。新Mac可先按[uv官方安装说明](https://docs.astral.sh/uv/getting-started/installation/)安装uv，再运行`uv run --python 3.14 --no-project .vscode/configure-python.py`。

## 两端使用同样的验证步骤

在本仓库根目录的终端执行：

```text
python --version
python -m pip --version
python python_practice/00_environemnt/hello.py
```

现有脚本应输出`Hellow World`，这是用户原来写的文字。编辑器中打开Python文件后，Ctrl+F5运行，F5调试；Mac的功能键可能需要同时按Fn。也可以选择`Python: 当前文件（Windows / Mac）`启动项。

目前Mac已验证普通运行、调试后端、pip对应关系、项目环境切换及所需扩展。Windows只有在本机完成以上操作并确认输出后，才能记为“已运行验证”。

## 同步与后续依赖

将源码和共享配置同步到另一台电脑即可；环境目录与`__pycache__`不提交到仓库。当前练习只使用标准库，暂不增加第三方依赖。有依赖的项目以后用依赖清单在两端分别安装。
