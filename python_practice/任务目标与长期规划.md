## 1. 学习起点与教学约定

你已有 C++ 项目经验，接触过变量、分支、循环、函数、容器、类、异常和泛型。它们可以帮助理解编程问题，但不表示对应的 Python 写法和语义已经掌握。Python 实践从零记录，熟悉的通用概念简讲，语言差异重点实验。

- 每次开始，完整读取本文件与《当前进度.md》，依据用户截图与反馈，从“下次从这里继续”恢复。
- 保持 C++ 学习时的节奏：解释一个新知识点 → 你实现一个小功能 → 运行并检查结果 → 用自己的话解释。不要连续多轮只做口头预测。
- 一个学习回合只引入一个主概念；一个项目可分多次完成，不一次抛出整份实现要求。
- 目录约定：每个项目一个文件夹，同一项目的知识点练习直接复用现有文件，必要时添加有意义的 .py 文件；只在开始独立新项目时由助手创建文件夹。保留已有练习代码，不按每个知识点创建子目录。
- 默认由你编写练习代码；助手负责拆解语法、分级提示、评审和验收。除非你明确要求，不代写整个项目或直接修改学习源码。
- 项目用于理解知识。达到目标就换项目，不为堆功能拖长练习；已理解的机械重复可跳过，并如实记录为口头通过或跳过实现。
- 2026-10-30用户再次确认已有C++基础，并明确跳过时长拆分的实现练习。对熟悉的通用概念简讲，优先练Python特有写法和语义；用户指定跳过的实现不在后续任务中变相要求补做。Python语言差异仍按实际代码或简短实验核对。
- 每项任务说明改动位置、一个新概念、预期行为与验收条件。评审区分必须修复、建议改进、可选拓展。
- 用户要求记录、整理或结束学习时更新进度：代码是否存在、运行证据、理解程度、遗留问题和下次第一步。不能把已讲解、编辑器无报错或 C++ 中学过记成 Python 已掌握。
- 中文讲解，先把语法拆清楚，再组合使用。C++ 对比只用于澄清，不强行对应指针、引用、模板或 RAII。

- 代码评审仅依据用户提供的截图与输出，不读取或执行练习源码核验；用户明确要求文件操作时按请求处理。

## 3. 长期验收目标

完成主线后，应能独立：

1. 编写并运行脚本，理解缩进、表达式、数值和字符串，处理输入、分支与循环。
2. 根据需求选择 list、tuple、dict、set，使用切片、解包、遍历、排序和简单推导式。
3. 解释名称绑定、可变与不可变对象、别名、浅拷贝、参数传递、`==` 与 `is`；识别可变默认参数问题。
4. 编写职责清楚的函数，使用返回值、关键字参数、默认值、作用域和模块；理解函数也是对象。
5. 读取错误回溯，捕获合适的异常，用 `with` 管理文件，处理编码、路径和坏数据。
6. 使用类表达确实需要的数据与行为，解释实例属性、类属性、self、组合、继承和鸭子类型。
7. 区分可迭代对象、迭代器与生成器，编写逐行处理数据的流水线。
8. 完成一个可复现的小工具，附使用说明、输入样例、关键测试；能说明数据如何输入、变换、保存及失败。

## 4. 项目路线

以下目录为计划，尚未创建的项目不能视为已有代码。每个箭头表示可拆开的学习步骤，并非一次课全部实现。

### 项目0：运行环境确认

计划目录：`00_environment/`。对应教程：“安装Python”“Python解释器”“第一个Python程序”“使用文本编辑器”“输入和输出”的输出部分。

任务：检查现有解释器 → 用`print()`输出一行文字 → 由你创建并运行`00_environment/hello.py` → 区分终端、交互式解释器和脚本 → 确认工作目录和VS Code解释器。每一步单独讲解，暂不引入第三方包。

第一课只练“用Python脚本输出内容”：先理解`print("Hello, Python!")`中的函数名、括号和字符串，再自己添加一行输出。暂不加入输入、分支或循环。后续补完编辑器运行与交互模式确认，再进入项目1。

验收：能够从终端和编辑器运行同一个脚本，说明实际解释器位置与版本，能识别`>>>`提示符与终端提示符。助手检查本机命令行可运行，只证明该命令可用；你的编辑器配置、亲手编写和独立运行仍须分别确认。

### 项目1：学习时长计算器

计划目录：`01_study_timer/`。对应教程：“输入和输出”“数据类型和变量”“条件判断”“循环”；需要时提前阅读“错误处理”。

产物：输入学习分钟数，输出小时和剩余分钟；逐步支持多次记录与退出。

2026-10-30安排调整：时长拆分的算术实现按用户要求跳过，不作为后续语法学习的前置条件；继续推进f-string及Python条件、循环与错误处理的写法。跳过的部分如实记录，不假称已有相应源码或运行验证。

递进：`input` 返回字符串 → `int` 转换与变量 → `//`、`%`、输出 → 条件与缩进 → `while`、退出命令 → 单独引入 `try/except ValueError` 处理错误输入。

验收：135输出2小时15分钟；0输出0小时0分钟；负数提示无效；输入文字不会使最终版本直接退出；退出命令生效。第一回合只处理合法整数，其余能力分次增加。

重点差异：`/` 与 `//` 不同；不要求变量先写类型声明；缩进定义代码块；`input` 不自动变成数字。

### 项目2：内存中的学习清单

计划目录：`02_study_list/`。对应教程：“字符串和编码”“使用list和tuple”“循环”，以及“高级特性”中的切片、迭代、列表生成式。

产物：新增、展示、查找、删除学习事项，程序结束后暂不保存。

递进：list与append → `for`、`enumerate` → 下标与切片 → `strip`、成员判断 → 删除与空列表 → 元组解包 → 简单列表推导式。

专项小实验：`b = a` 与 `a.copy()`；修改列表与重新绑定名称；嵌套列表浅拷贝为何仍共享内部对象。字符串不可变，列表可变。

验收：空清单可展示；空白事项拒绝；首项、末项和非法编号正确处理；解释显示编号与零起始下标的关系；能预测别名和浅拷贝实验。遍历时删除的问题按功能需要讲解。

### 项目3：文本词频与查询工具

计划目录：`03_word_counter/`。对应教程：“使用dict和set”“函数”“模块”；结合“高阶函数”“sorted”理解函数作为参数。

产物：先分析内存文本，统计词频、去重词和查询结果；文件输入留给下一项目。

递进：`split`、`lower` → dict累计与get → set去重 → `items`解包 → 定义标准化与统计函数 → `return`、None与作用域 → `sorted(key=...)`与函数对象 → 主程序和模块分离、`if __name__ == "__main__"`。

函数参数分次补充：位置/关键字参数、默认值、`*args`和`**kwargs`的收集与调用解包。无需为了练语法把每个函数都写成可变参数。用短实验理解默认列表参数共享；递归可用独立小练习，不强行加入词频统计。

验收：`Hello hello Python`中hello为2、python为1；空文本返回空统计；查无此词不插入新键；明确大小写和标点规则。简单空白分词不宣称支持中文分词。解释 `dict` 缺键访问与 `get` 的区别。

### 项目4：文件测量记录分析器

计划目录：`04_measurement_analyzer/`。对应教程：“错误、调试和测试”的错误处理与调试、“IO编程”的文件读写、操作文件和目录、序列化；补充标准库pathlib和csv。

产物：逐行读取“名称 数值”文件，报告坏行与行号，按名称汇总并导出报告。

递进：`with open(..., encoding="utf-8")`与文件迭代 → pathlib与相对路径 → 每行split及float转换 → 精确捕获转换错误、坏行后继续 → 函数分工与分组统计 → csv/json保存和读取 → `raise`与`finally`的适用情形。

验收：混合合法行、非法数值、额外字段和零值；文件不存在、空文件与空分组得到清楚处理。明确空行策略；不以平均值0表示无数据；解释float精度限制。非有限数值是否接受需制定规则并验证。输出报告与原始输入分开，避免覆盖输入。

重点差异：名称绑定到对象，不直接套用C++引用参数；`with`保证离开上下文时关闭文件，不依赖对象何时销毁；异常处理范围应尽量小。

### 项目5：学习任务与会话管理器

计划目录：`05_task_manager/`。对应教程：“面向对象编程”，以及“面向对象高级编程”中的property、定制类；结合“返回函数”“装饰器”做独立实验。

产物：用Task保存标题与完成状态，用管理器组合多个任务；按需要保存记录。

递进：class、实例和self → `__init__`与实例属性 → 方法 → 类属性共享陷阱 → 组合 → `__repr__`与`__len__` → 需要约束时引入property。

继承与多态用一个小的“不同报告输出器”练习：先以相同方法接口演示鸭子类型，再比较继承与组合；有需要再讲super和抽象基类，不强制重构整份管理器。装饰器语法先借property认识，再用短实验理解函数包装；staticmethod/classmethod、闭包和lambda按实际需要分次补充。

验收：两个实例的任务列表互不串用；完成状态改变正确；非法标题有规则；能解释self如何传入、实例属性与类属性的区别、`__init__`负责初始化。不把命名约定或双下划线当作C++访问控制。`__slots__`、多重继承、枚举和元类先了解用途，按实际需要选学；不把元类作为基础过关条件。

### 项目6：日志筛选与报告流水线

计划目录：`06_log_pipeline/`。对应教程：“高级特性”的生成器、迭代器，“IO编程”的文件读写，以及“正则表达式”。

产物：逐行读取日志，筛选级别/关键字，按需生成结果；随后添加简单正则字段提取。

递进：可迭代对象与iter/next → StopIteration → 生成器表达式 → yield → 组合读取/解析/筛选 → 文件上下文与延迟执行 → 适合时引入re。

验收：空文件和无匹配正常结束；连续两次遍历同一生成器能解释结果；文件在实际迭代期间保持打开；处理流程不要求先把整个文件读入列表。递归生成器、send等高级功能作为可选拓展。

### 项目7：带回归测试的命令行工具

在项目4或6中择一升级，不要求重复做相似项目。对应教程：“模块”“错误、调试和测试”“常用内建模块”中的argparse和venv；logging按官方文档补充。

验收：正常数据、空数据、坏行和缺文件有可复现验证；导入模块不会直接启动交互；从明确的工作目录按说明可运行。类型标注作为可读性补充，解释标注通常不自动执行类型检查。测试服务真实边界，不追求测试数量。

### 项目8：综合项目，二选一

A. 学习记录数据库：对应教程“访问数据库”中的“使用SQLite”，使用sqlite3保存学习记录，逐步加入增删改查、参数化SQL、事务、按日期统计。验收重启后数据保留、空查询、回滚和含引号文本；先讲数据库基础再写功能。MySQL与ORM留到有实际需求时再学。

### Windows 与 Mac 的仓库同步约定

远程仓库：<https://github.com/Lover-Leo/Code-Learing>；共享分支：`main`。两台电脑同步整个代码仓库，包括学习源码、两份学习文档、跨平台环境说明、`.vscode`通用配置与安装工具、Python版本约定，以及仓库中的参考资料。


安装成功后重启VS Code及终端。若工作区以前选过其他Python，使用`Python: Select Interpreter`选择当前用户目录下`.local/share/venvs/python-default/Scripts/python.exe`。Mac使用对应环境中的`bin/python`。两端都可选择`Python: 当前文件（Windows / Mac）`启动项，Ctrl+F5运行、F5调试。
