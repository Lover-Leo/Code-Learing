## 1. 输入、输出与字符串

```python
print("Hello")                  # 默认末尾换行
text = input("请输入：")         # 返回str，即使输入135也是字符串
minutes = int(text)              # 接收转换返回的整数，不会原地修改text
print(f"本次学习了{minutes}分钟") # f-string中花括号内可以放表达式
```

- 字符串中的`\n`是换行；print默认也会添加换行。
- 终端提示符`%`和Python交互模式`>>>`不同；在终端输入python进入交互模式，exit()退出。
- `text.strip()`返回去掉首尾空白的新字符串，中间空格保留。
- `text.lower()`返回字母转为小写的新字符串，不修改原字符串。

## 2. 缩进、条件与循环

Python用缩进划分代码块，通常每级4个空格；if/elif/else、for、while、try/except等语句头部末尾有冒号。

```python
while True:
    text = input().strip()
    if text == "q":
        break
    if not text:
        continue
    print(text)
```

- break退出当前循环；continue跳过本轮剩余部分。
- 对字符串而言，`if not text`等价于判断`text == ""`。含空格的字符串不是空字符串，先strip再判断。
- Python的not、and、or对应C++常用的逻辑非、与、或；注意具体返回值语义不完全相同，后续按需补充。
- `1 <= number <= len(tasks)`是链式比较；len返回元素数量。

## 3. 列表list：添加、遍历、切片、删除

```python
tasks = ["Python", "C++", "英语"]
tasks.append("阅读")
for number, task in enumerate(tasks, start=1):
    print(f"{number}. {task}")
```

enumerate逐项提供“编号、元素”，左边按位置解包；变量名不负责自动识别。start=1改变编号起点，不改变列表下标从0开始的事实。

| 写法 | 含义 |
|---|---|
| tasks[0] | 第一项 |
| tasks[-1] | 最后一项 |
| tasks[0:2] | 下标0、1，包含起点、不含终点 |
| tasks[1:3] | 下标1、2 |
| tasks[::2] | 从头每隔2个位置取一项 |
| text in tasks | 列表中是否有与text相等的元素 |
| tasks.remove(value) | 删除第一个相等的值；不存在时抛ValueError；返回None |
| tasks.pop(index) | 按下标删除并返回被删元素；不传下标时删除最后一项 |

用户编号转下标用`number - 1`，删除前判断`1 <= number <= len(tasks)`，防止编号0意外变成下标-1。空列表不能直接pop。

## 4. 名称绑定、别名与浅拷贝

```python
a = ["A", "B"]
b = a
c = a.copy()
b.append("C")
b = ["D"]
# a为["A", "B", "C"]；b为["D"]；c为["A", "B"]
```

`b = a`让两个名称指向同一对象；append修改对象，而`b = ["D"]`只改变b的指向，不改a。

copy只复制外层列表。若包含内部列表，内层仍共享：

```python
a = [["A"], ["B"]]
c = a.copy()
c[0].append("C")  # a和c都能看到内部列表的变化
c.append(["D"])  # 只改变c的外层，a不增加这一项
```

## 6. 列表推导式与关键词筛选

```python
matched = [task for task in tasks if keyword in task]
```

通用结构：`[结果表达式 for 变量 in 可迭代对象 if 条件]`。结果表达式决定放进新列表的值；这里task表示原样保留事项。遍历所有元素，保留全部匹配，顺序不变；无匹配返回[]，不修改原列表。

- `keyword in task`：字符串是否包含子串，默认区分大小写。
- `keyword.lower() in task.lower()`：先统一小写再比较，结果仍可保留原task。
- 空字符串是任何字符串的子串，空关键词会匹配所有事项。
- `[n * 2 for n in [1, 2, 3]]`得到[2, 4, 6]，结果表达式是n * 2。

## 7. 错误处理

```python
try:
    number = int(input("请输入编号："))
    # 使用number的判断与操作应在转换成功后执行
except ValueError:
    print("请输入整数")
```

ValueError是内置异常类，大小写必须正确，不是随意起的变量名。转换失败会跳过try内后续语句进入except，处理完再继续。不要在转换失败后无条件使用尚未赋值的number。优先捕获明确类型，避免裸except。

## 11. 函数定义、调用、return与局部变量

```python
def count_word(text):
```

## 12. 参数语法速查

```python
def count_word(text, ignore_case=True):
    if ignore_case:
        text = text.lower()
    words = text.split()
    count = {}
    for word in words:
        count[word] = count.get(word, 0) + 1
    return count
```

定义中的ignore_case=True设置默认值。调用中的ignore_case=False是本次明确传值，不会改写定义中的默认值。ignore_case是自定义参数名。

```python
count_word("Hi hi")                     # {"hi": 2}
count_word("Hi hi", False)              # {"Hi": 1, "hi": 1}
count_word(ignore_case=False, text="Hi hi")  # 同上，按名传参可调整顺序
```

普通位置实参必须放在关键字实参前；count_word(text="Hi hi", False)语法错误。

| 定义形式 | 规则 |
|---|---|
| def f(a, b=2) | 普通参数可按位置或名称传；b省略才用默认值 |
| def f(*args) | 多余位置参数收集为元组；无参数为()，单个为(value,) |
| def f(**kwargs) | 多余关键字参数收集为字典；无参数为{} |
| def f(a, *, b) | a可按位置或名称传；b只能按名称传 |
| def f(a, /, b) | a只能按位置传；b可按位置或名称传 |

*args、**kwargs中的名称可以更换，星号决定收集方式。单独的*只作参数分隔，不收集参数。

### 定义时收集，调用时解包

```python
def show_pair(first, second):
    print(first, second)

show_pair(*["Python", "C++"])
show_pair(**{"first": "Python", "second": "C++"})
```

调用时*展开为位置实参，**展开为关键字实参。字典键名必须符合函数接收的参数；将second改成third不能靠顺序匹配，会抛TypeError。参数数量、重复赋值等也须符合签名。

### 综合绑定示例

```python
def demo(a, /, b=2, *args, c=3, **kwargs):
    print(a, b, args, c, kwargs)

demo(1, 4, 5, 6, c=7, name="Leo")
# a=1, b=4, args=(5, 6), c=7, kwargs={"name": "Leo"}
demo(1, c=7)
# a=1, b=2, args=(), c=7, kwargs={}
```

先按位置为a、b传值，多出来的才进args。b=2不是固定值，传入4后就用4。最后一道默认参数综合题已口头通过。

## 13. 可变默认参数陷阱

## 15. 词频项目：排序与lambda

```python
for word, times in sorted(
    count.items(),
    key=lambda item: (-item[1], item[0])
):
    print(f"{word}:{times}")
```

- lambda item: item[1]是单表达式匿名函数，相当于接收item并返回item[1]。
- sorted返回新的排序列表，不改原对象；key必须按名称传参，不能将lambda直接作为第二个位置参数。
- key为每个元素生成排序依据，不替换返回列表中的原元素，也不是双参数比较函数。
- (-次数, 单词)先按负次数升序，即原次数降序；次数相同时按单词升序。元组比较按位置依次进行。
- 字符串按Unicode码点逐字符比较，不只是首字母；共同前缀后继续比较。ASCII范围内顺序与ASCII一致。
- list.sort()原地排序，返回None；sorted(list)返回新列表。用户曾误答sort返回排序列表，已纠正，未另行验收。

截图证据：漏写key=引发TypeError后已修正，代码与python:2、hello:1输出正确；同次数排序写法正确，尚无实际同次数输入输出截图。排序依据已口头讲解，用户确认理解。

## 18. 文件项目预习：异常处理

```python
try:
    with open("notes.txt", encoding="utf-8") as f:
        text = f.read()
except FileNotFoundError as err:
    print("文件不存在")
else:
    print(text)
finally:
    print("处理结束")
```

- except处理匹配异常；else仅在try正常结束时执行；finally用于收尾，正常控制流下无论是否异常都会执行。
- 异常后跳过try中剩余语句，转到匹配except；变量未赋值时不可在后面无条件使用。
- ValueError、FileNotFoundError、ZeroDivisionError是内置异常类，大小写固定；as后err是自定义变量名。也可以先定义自己的异常类再捕获。

```python
def check_minutes(minutes):
    if minutes < 0:
        raise ValueError("分钟数不能为负数")
    return minutes
```

raise主动抛异常，后续语句停止，交由调用链中匹配的except处理。用户已正确解释负数异常信息与控制流。

多个except可以分别处理不同异常；共用同一处理逻辑时可用元组：

```python
try:
    number = int("abc")
    result = 10 / number
except (ValueError, ZeroDivisionError) as err:
    print(err)
```

### 路径与逐行解析

```python
from pathlib import Path
data_path = Path(__file__).resolve().parent / "records.txt"
```

pathlib是标准库；Path是其中的类，不需要另装。也可import pathlib并写pathlib.Path(...)。data_path是路径对象，不是文件内容，构造它不会打开文件。

```python
with open(data_path, encoding="utf-8") as f:
    for lineNumber, line in enumerate(f, start=1):
        if not line.strip():
            continue
        try:
            name, value_text = line.split()

            continue
```

```python
import math
# value转换成功后，分组之前
if not math.isfinite(value):
    print(f"第{lineNumber}行不是有限值")
    continue
```

float("nan")、float("inf")、float("-inf")可以转换成功，但不是有限值，不能仅靠ValueError拦截。0.0为有限值，应保留。截图已显示两条非有限值拒绝提示及humidity:0.0。

### 分组与汇总

```python
groups = {}
# 每次成功解析并通过检查后
if name not in groups:
    groups[name] = []
groups[name].append(value)
```

初始化仅在键首次出现时执行，append放在if外以收集所有记录。groups.items()每次提供(name, values)，values为该名称的列表；items()是字典方法，和自定义变量名item不同。

```python
for name, values in groups.items():
    total = len(values)
    average = sum(values) / total
    print(f"{name}: 数量={total}, 平均值={average:.2f}")
```

sum求和，len取数量；:.2f固定显示两位小数，不改原数值。当前分组创建后立即append，每组非空；groups={}时循环不执行，不能把无数据误报为平均值0。

### 文本报告与JSON文件

```python
report_path = data_path.parent / "report.txt"
with open(report_path, "w", encoding="utf-8") as report:
    for name, values in groups.items():
        total = len(values)
        average = sum(values) / total
        report.write(f"{name}: 数量={total}, 平均值={average:.2f}\n")
```

报告与原始记录分开，w每次重新生成。write不自动换行。with不建立独立变量作用域，as f可重新绑定到新文件对象；前一个with结束时旧文件已经关闭，可用json_file等名称提升可读性。

```python
import json
json_path = data_path.parent / "groups.json"
with open(json_path, "w", encoding="utf-8") as json_file:
    json.dump(groups, json_file, ensure_ascii=False, indent=2)
with open(json_path, encoding="utf-8") as json_file:
    restored = json.load(json_file)
print(restored == groups)  # 本例为True
```

- dump/load对应文件，dumps/loads对应字符串；末尾s可记作string。
- ensure_ascii=True默认将非ASCII字符转义；False使中文直接可读。二者解码数据相同；实际文件编码由open的encoding指定。
- indent=2让JSON缩进显示。
- ==比较内容，is比较对象身份。load根据JSON重新构造字典和内部列表，本例不共享原内部列表，不是groups.copy()那种浅拷贝。
- JSON文本中键和字符串用双引号；Python外层字符串引号可为单引号。非法JSON解析抛json.JSONDecodeError；用dumps生成可避免手写引号混淆。

```python
text = json.dumps([1, 2, 3])  # str
restored = json.loads(text)  # list
```
