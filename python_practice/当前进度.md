## 4. 后续重点关注的语言差异

以下均为待学习主题，不能视为已讲解或掌握：

- 名称绑定与赋值：`b = a`不会自动复制列表；浅拷贝不等于递归复制。
- 参数传递：修改可变对象与重新绑定形参不同；默认参数对象可能跨调用共享。
- 数值：`/`、`//`、`%`及负数情形；浮点误差；动态类型不意味着随意混用字符串和数值。
- 条件：真值、None、空容器；`==`比较值，`is`比较身份，不用小整数或字符串缓存现象代替语义解释。
- 容器：list原地方法的返回值、切片边界、dict缺键、set无下标、tuple内部可包含可变对象。
- 生命周期：用with管理文件；不把C++析构/RAII规则照搬到Python对象回收。
- 类与函数：self、实例/类属性、默认参数、闭包、装饰器、鸭子类型、生成器的消耗与延迟执行。
